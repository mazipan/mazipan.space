[Coding Monster](https://coding-monster.mazipan.space/) is a native Android game for kids ages 5 to 12. Kids plan a path with simple blocks, press **Go**, and a new monster hatches into their collection.

Each world teaches one coding idea. Kids move on when they are ready. The game is free, works offline, needs no account, and collects no personal data.

The app is in closed testing on Google Play. The source code is private.

## ✨ Features

- **7 worlds** - sequences, loops, conditions, debugging, smart loops, pathfinding and functions
- **100+ coding puzzles** - built from blocks, no typing
- **40+ monsters** - hatch them, help them evolve in 3 stages, and collect them all
- **Kid-safe** - no accounts, no personal data, kid-safe ads, works offline
- **Bilingual** - English and Indonesian

## 🗂️ Tech Stacks

- Kotlin
- Jetpack Compose
- Android
- Astro (website)
