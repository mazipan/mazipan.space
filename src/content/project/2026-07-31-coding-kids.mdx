[CodeKids](https://coding.mazipan.space/) is a free web app where kids ages 5 to 14 learn to code and train their brain. Everything runs in the browser. No account, no download, no ads.

Most kids' coding apps lock lessons behind a login or a subscription. I wanted something a parent can open and hand to a child right away. Lessons are short puzzles, and progress is saved on the device.

## ✨ Features

- **Block Coding** - write code with visual Blockly blocks across 7 main worlds and 8 bonus worlds (sequences, loops, variables, conditions, functions, arrays)
- **Brain Training** - 15 worlds of pattern, logic, math, memory and reasoning puzzles, no code editor needed
- **Digital Citizenship** - 4 worlds on passwords, privacy, kindness and spotting scams
- **XP and stars** - one shared level system across all three paths
- **Bilingual** - English and Indonesian, picked from the browser language

## 🗂️ Tech Stacks

- React
- TypeScript
- Blockly
- Tailwind CSS v4
- Vite
- Bun
