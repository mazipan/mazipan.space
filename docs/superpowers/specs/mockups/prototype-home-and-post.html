Intro to Intersection Observer

2018-04-16 - 4 min read - Short read
Bottom line: Use it to know when something enters the screen. No scroll listeners needed.

The problem

For a long time we watched the scroll event to know if an element was visible. It works, but it runs again and again, and it makes the page feel slow.

A simple example

The browser can tell us when an element enters the screen. We only say what to watch.

const io = new IntersectionObserver((entries) => {
  entries.forEach((e) => e.isIntersecting && show(e.target));
});
io.observe(document.querySelector('.card'));
